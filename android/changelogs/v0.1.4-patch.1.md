## Yugen v0.1.4 patch 1

**Cloudstream plugins now live in Extension stores**, and the extension manager understands both engines.

### Changed
- **Cloudstream plugins moved into Extension stores.** Settings > Extensions > **Extension stores** now has two tabs, **Stores** and **Cloudstream**. The Cloudstream tab is the old plugin page: installed plugins, repositories, install from URL or file, and reload. The separate *Cloudstream plugins* row in Extensions settings is gone, and the refresh button reloads whichever tab you are on.
- `cloudstreamrepo://` links open Extension stores and add the repository.

### Added
- **Streaming extension manager shows both engines.** Each Streaming row carries a **CS3** (Cloudstream) or **APK** (Aniyomi) badge, and a new **engine filter** chip cycles *All engines*, *Aniyomi* and *Cloudstream*.
- **Cloudstream repositories are tabs** next to the Aniyomi stores. Each lists its plugins with **Install** and **Update**, installed ones are grouped under Anime and TV & Movies, and the language, 18+ and search filters apply. **Update all** includes Cloudstream plugins.
- **Plugin settings.** The settings button on an installed Cloudstream plugin lets you override each provider's website address, for sites whose default domain is blocked or has moved. Clearing a field restores the plugin's own address.
